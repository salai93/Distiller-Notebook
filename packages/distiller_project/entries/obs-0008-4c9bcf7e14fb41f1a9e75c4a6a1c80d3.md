## LA component DSM: findings

**Model:** Distiller-Project @ master 85234811. The matrix covers 14 logical components (5 internal, 9 actors) and the 12 LA component exchanges between them, read as row sends to column.

### Exchanges
- Pipeline: Water Source → Condenser
- HeatSupply: Heat Source → Evaporator
- WaterSupplyControl: Operator → Water Source
- HeatSupplyControl: Operator → Heat Source
- HotWater: Condenser → Diverter
- DistributionPipeline: Condenser → Water Distribution System
- HotWaterDiverter1: Diverter → Evaporator
- BypassFeed: Diverter → Excess Water Discharge
- Steam: Evaporator → Condenser
- Drainage: Evaporator → Drain
- WastePipeline: Drain → Waste Management System
- ConsumerPipeline: Water Distribution System → Water User

### Findings
1. **One coupled cluster:** Condenser → Diverter → Evaporator → Condenser. Steam is the only feedback mark below the diagonal. It is the heat-recovery loop: these three components can't be designed independently and should be treated as one module or integration unit.
2. **Operator Interface has no interfaces at all in LA.** It has no ports or component exchanges, although it hosts Provide User Interface, whose functional exchanges OperateDistiller and Feedback connect to the Operator's Operate System. Those functional exchanges aren't allocated to any component exchange. In PA the same link exists as Operate (Operator → User Interface), so LA and PA are inconsistent.
3. **Maintenance Personnel and Deployment Personnel have no component exchanges.** Their functions (Maintain & Service System, Install System, Certify System) exchange data with Allow Maintenance & Service and Provide Deployability, but no component exchange carries it.
4. **Operator controls only the external sources at LA** (WaterSupplyControl, HeatSupplyControl). It doesn't interface with the distiller itself.
5. **HotWaterDiverter1 and BypassFeed carry functional exchanges but no exchange items.**
6. Drain and the external sinks are pure receivers or forwarders, with no feedback.
