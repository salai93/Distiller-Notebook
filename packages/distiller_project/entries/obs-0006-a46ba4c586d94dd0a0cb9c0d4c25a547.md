## Behaviour
1. **Startup:** Operate System → Startup → Provide Operator Interface → Initialize → Monitor Operation.
2. **Running:** Monitor Operation reports power, operating and draining lamp states to Provide Operator Interface.
3. **Shutdown:** Operate System → Shutdown → Provide Operator Interface → Shutdown → Monitor Operation.

## Observations relevant to simulation
- The chain is control and indication only. It has no water or heat flow, so it cannot be simulated on its own. PA Distill Water probably carries the process side (not yet reviewed).
- No component, actor or physical-link allocations appeared in the chain data, so which components run these functions is not yet known.
- The chain has no description, and the duplicate "Shutdown" name is ambiguous.
- LA "FunctionalChain 1" still has the default name and may be a stub.
- LA Distill Water and Maintain System appear to be realized by the PA chains of the same name. This was not verified.
