## LA DSM optimization and recommendations (proposal, not applied)

**Model:** Distiller-Project @ master 85234811. Follows OBS-0008.

### Sequencing
New order: drivers (Operator, Maintenance) → sources (Water Source, Heat Source) → control module (Operator Interface, Controller) → distillation core (Diverter → Evaporator → Condenser) → Drain → sinks.

With the existing exchanges, exactly **one** mark sits below the diagonal. The heat-recovery loop is a strongly connected component, so one feedback mark is the minimum: no reordering removes it.

**Recommended tear point:** HotWater (Condenser → Diverter, the preheated feed). It is cheaper to assume a preheat temperature and iterate than to assume steam flow (the Steam tear in the original order). The Phase Change Heat Transfer constraint already sits on Steam.

### Clustering
- **Distillation core** = Diverter + Evaporator + Condenser. Suggested as a parent LA component ("Distillation Unit"). Its boundary would be 2 inputs (Pipeline, HeatSupply) and 3 outputs (DistributionPipeline, BypassFeed, Drainage).
- **Control module** = Operator Interface + a new Controller.

### Gaps against the PA
PA component exchanges with **no LA counterpart**:
- Operate
- ControlIF
- Processor-Feed
- Processor-Drain
- Processor-Boiler
- Divert
- BypassFeedPipe

The LA BypassFeed has no PA realization either.

PA Processor realizes the LA Operator Interface, so HMI and control are merged into one LA component. PA Feed (Throttle) realizes no LA component.

### Recommendations
1. **Split the LA Operator Interface** into Operator Interface (HMI) and a new Controller. Add exchanges: Operate (Operator → Operator Interface), ControlIF in both directions, and Controller → Diverter / Evaporator / Drain (feed, boiler and residue control) to match the PA.
2. **Add sensing back to the Controller** (Evaporator level/temperature → Controller). It is missing in PA too: the PA function Monitor Operation has no plant inputs.
3. **Give Maintenance Personnel an interface**, for example service access to the Evaporator or Drain for descaling. Deployment Personnel stays boundary-only unless install or certify interfaces are modeled.
4. Add exchange items to HotWaterDiverter1 and BypassFeed. Link PA BypassFeedPipe to LA BypassFeed, and link PA Feed to the LA Diverter.
5. Review whether the Operator should control the Heat Source and Water Source directly, or through the Controller.
