## Naming review: components and functions, all layers

**Model:** Distiller-Project @ master, commit 973e572.
**Scope:** OA entities and activities; SA, LA and PA components, actors and functions.

1. **"Operartor Interface"**: LA logical component, uuid b1bd7327-f379-428a-a630-7ff7a7498477. Should be "Operator Interface".
2. **"Provide Deploymentability"**: appears in all four layers (OA bb2e8782…, SA 0b5b2e54…, LA 9a7bf6d7…, PA 1d19c719…). "Deploymentability" isn't a word; "Provide Deployability" is the likely intent.
3. **"Water Distiller "**: PA node component, uuid 23790146-db2e-4eeb-8334-384d01af3161, has a trailing space. The SA component is "Water Distiller" with no space.

### Inconsistencies (not typos)
- The operator-interface function is named "Provide User Interface" in LA (fcc3e1b1…) but "Provide Operator Interface" in PA (14b6ba5c…). The LA component is "Operartor Interface"; the PA behavior component is "User Interface".
- Exchange and link names mix naming styles, e.g. internalDrainPipe, Condenser-TFitPipe, CleanWaterDistributionPipeline. This is cosmetic.

All other activity, function and component names are spelled correctly. The two PA "Condenser" elements (one physical node, one behavior component) are a deliberate pattern, not a duplicate.
